# AI Deepfake Detection Service

Python FastAPI microservice for AI-powered deepfake detection with GPU acceleration.

## 🚀 Features

- **FastAPI** framework for high-performance async API
- **GPU acceleration** with NVIDIA CUDA support
- **EfficientNet-B0** backbone for efficient inference
- **Perceptual hashing** (pHash) for image similarity detection
- **768-dimensional embeddings** for vector similarity search
- **Batch processing** support for video frame analysis
- **Health checks** and monitoring endpoints
- **Docker** containerization with GPU support

## 🔧 Installation

### Option 1: Docker (Recommended)

```bash
# Build and run with docker-compose
docker-compose up --build ai-service

# Or build standalone
cd ai-service
docker build -t ai-service .
docker run -p 8000:8000 --gpus all ai-service
```

### Option 2: Local Development

```bash
# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Install PyTorch with CUDA
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118

# Run the service
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

## 📡 API Endpoints

### Health Check

```bash
GET /health
```

**Response:**

```json
{
  "status": "healthy",
  "model_loaded": true,
  "gpu_available": true
}
```

### Single Image Analysis

```bash
POST /analyze
Content-Type: multipart/form-data
```

**Request (multipart):**

```bash
curl -X POST "http://localhost:8000/analyze" \
  -F "file=@image.jpg"
```

**Request (JSON with base64):**

```bash
curl -X POST "http://localhost:8000/analyze" \
  -H "Content-Type: application/json" \
  -d '{"image_base64": "iVBORw0KG..."}'
```

**Response:**

```json
{
  "ai_score": 0.876,
  "phash": "8f373e7c78787c78",
  "embedding": [0.123, -0.456, ...],
  "is_flagged": false,
  "inference_time_ms": 245,
  "sha256": "a1b2c3d4..."
}
```

### Batch Analysis

```bash
POST /analyze/batch
Content-Type: multipart/form-data
```

**Request:**

```bash
curl -X POST "http://localhost:8000/analyze/batch" \
  -F "files=@frame1.jpg" \
  -F "files=@frame2.jpg" \
  -F "files=@frame3.jpg"
```

**Response:**

```json
[
  {
    "ai_score": 0.876,
    "phash": "8f373e7c78787c78",
    "embedding": [...],
    "is_flagged": false,
    "inference_time_ms": 245,
    "sha256": "..."
  },
  ...
]
```

## 🎯 Model Options

The service supports multiple model backends:

### 1. EfficientNet-B0 (Default)

- **Speed**: ~50ms per image (GPU)
- **Accuracy**: Good general-purpose detector
- **Memory**: ~16MB

### 2. CLIP-based

- **Speed**: ~100ms per image (GPU)
- **Accuracy**: Excellent semantic understanding
- **Memory**: ~400MB

### 3. Custom Model

Place your pretrained weights in `models/deepfake_detector.pth`

## 🚀 Performance Optimization

### GPU Acceleration

- Uses FP16 (half precision) on GPU for 2x speedup
- Batch processing for video frames
- Async inference to avoid blocking

### Typical Performance

- **GPU (RTX 3080)**: ~50ms per image
- **CPU (Intel i7)**: ~200ms per image
- **Batch (8 images)**: ~150ms total on GPU

## 🔗 Integration with Node.js

```javascript
// Node.js example
const FormData = require("form-data");
const axios = require("axios");
const fs = require("fs");

const form = new FormData();
form.append("file", fs.createReadStream("image.jpg"));

const response = await axios.post("http://ai-service:8000/analyze", form, {
  headers: form.getHeaders(),
});

console.log(response.data);
// { ai_score: 0.876, phash: "...", embedding: [...], ... }
```
